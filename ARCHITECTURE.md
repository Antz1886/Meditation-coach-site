# The AgentMesh Philosophy

The Mind-Craft Coach is built on the **AgentMesh** design—a decentralized, resolution-first architecture where AI and humans collaborate as a unified workforce.

## Core Pillars

1. **Resolution-First Logic**: We don't measure success by "completion time," but by "mental state resolution." The AI's goal is to transition the user from a state of high entropy (stress) to low entropy (clarity).
2. **The 200ms Threshold**: By leveraging Gemini 3 Flash and ElevenLabs Flash v2.5, we aim for "instant" reactivity. The UI (Gravity Well) provides immediate visual feedback, while the backend orchestrates the voice loop in near real-time.
3. **The Human Bridge (Service Delivery)**: When the AI identifies a recurring pattern or a need for deeper intervention, it seamlessly bridges the user to a human coach. This is managed via Zoho FSM, treating wellness like a "critical dispatch" mission.

## Tech Stack Overview

- **Frontend**: "Mission Control" UI using Web Audio API for frequency-reactive visualizers.
- **Backend**: FastAPI orchestrating Gemini 3 Flash (LLM) and ElevenLabs (TTS).
- **Integrations**: Zoho CRM for lead capture and Zoho FSM for technician-style coach dispatch.
