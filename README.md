# Antigravity Agent: Resolution-First Meditation

> "Stop completing tracks. Start resolving states."

The Antigravity Agent is a production-grade Agentic Workforce platform designed to provide instant mental clarity through AI-driven "Micro-Resets" and seamless human coaching integration.

## 🚀 Vision
Built for the 2026 "Instant Economy," this platform uses Gemini 3 Flash and ElevenLabs Flash v2.5 to provide a voice-first, low-latency meditation experience. It treats mental wellness as a system uptime problem—resolving "mental lag" with precision.

## 🛠️ Tech Stack
- **Brain**: Gemini 3 Flash (Multi-modal reasoning)
- **Voice**: ElevenLabs Flash v2.5 (~75ms latency)
- **UI**: Mission Control (Glassmorphism + Web Audio API)
- **Ops**: Zoho CRM + FSM (Service Delivery & Dispatch)

## 📁 Repository Structure
- `/frontend`: "Mission Control" UI (HTML5/CSS3/JS)
- `/agent-logic`: Python/FastAPI backend (Orchestrator)
- `/integrations`: Zoho & Zapier connectivity
- `ARCHITECTURE.md`: The AgentMesh Philosophy

## 🚦 Getting Started
1. **Frontend**: Open `frontend/index.html` in your browser.
2. **Backend**:
   ```bash
   cd agent-logic
   pip install -r requirements.txt
   python main.py
   ```
3. **Environment**: Add your `GEMINI_API_KEY` and `ELEVEN_LABS_API_KEY` to a `.env` file in the root.
